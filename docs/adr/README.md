# SCC Architecture Decision Records

Each file records the decision as accepted on its own date. A later ADR can extend the product without rewriting the earlier file. Current bounds are in [../limitations/current.md](../limitations/current.md), not in the oldest row that still says a feature was deferred.

ADR-065 through ADR-068 record a time when parametric STEP, Sweep, or Loft were still deferred or only partly decided. ADR-069 admits bounded v2 models to the formal STEP path. ADR-075 and ADR-076 add bounded Sweep and Loft. Those later decisions do not make either feature unrestricted.

## Status words

- **Accepted**: implementations of that decision follow the file.
- **Accepted for a version or phase**: the decision is scoped to that slice. Read the body before treating it as the whole product.
- A historical deferral inside an older ADR is history. Check the limitation page before repeating it as a current claim.

## Adding a record

1. Use the next free number.
2. Include context, decision, rejected alternatives, consequences, and how the change stays fail-closed.
3. Add a row here.
4. If the public feature table changes, update both READMEs and `docs/limitations/current.md` in the same change.
5. Leave older ADR bodies intact.
