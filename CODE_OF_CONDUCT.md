# Code of conduct

AICAD is an engineering project. Discussion is about the model, the geometry,
the drawing, the STEP evidence, and the code that produces them.

## Expected behavior

- Critique the change, the test, and the claim. Leave the person alone.
- Write reproducible reports: command, input, error code, and what you expected.
- Mark uncertainty as uncertainty. Do not present a skipped test as a pass.
- Respect the fail-closed rule. An unsupported operation stays an error.
- Give credit for third-party software. Do not claim the kernel or another
  author's work as original AICAD work.

## Unacceptable behavior

- Harassment, slurs, or sexual attention directed at another person.
- Publishing someone else's private information, credentials, or keys.
- Deliberately submitting fabricated screenshots, STEP files, or test results.
- Sabotaging review, or pressuring a maintainer to hide a limitation.

## Reports

Report conduct problems the same way as security issues until a public
tracker exists: a private message to the repository owner, not a public
issue that spreads personal data. Maintainers may hide or edit comments
that publish credentials or personal data. They may reject changes that
weaken validation to obtain a green result.

This is a project policy written for AICAD. It is not the Contributor Covenant.
